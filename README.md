# Guru Karthikeyan V — AI Portfolio

A modern responsive portfolio website built with HTML, CSS, JavaScript and Bootstrap.

## Run
1. Open the folder in VS Code.
2. Open `index.html` with **Live Server**.
3. The portfolio will run in your browser.

## Personalize
- Replace `your-email@example.com` with your email.
- Replace the LinkedIn URL with your actual LinkedIn profile.
- Add more projects inside the Projects section.
- Add your resume PDF and connect it to a Resume button if required.

## Files
- `index.html` — portfolio structure
- `style.css` — design, responsive layout and dark/light theme
- `script.js` — typing animation, theme switcher, scroll button and contact form behavior
